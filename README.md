# Certi Monitor

O **Certi Monitor** é um sistema desenvolvido para auxiliar pessoas quem fazem a gestão de certificados, ou possui muitos. Ele faz o monitoramento da validade dos certificados digitais.

## Sobre o Projeto
O objetivo do sistema é permitir o cadastro de informações de certificados (nome, emissor, data de emissão, data de vencimento) e automatizar o acompanhamento da validade de cada um deles (Válido, Próximo do Vencimento ou Vencido)
